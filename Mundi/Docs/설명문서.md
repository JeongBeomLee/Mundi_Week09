# 🎮 Infinity Runner Game - 플레이 가이드

## 📖 게임 소개

**Infinity Runner**는 중력 전환 메커니즘을 활용한 3D 러너 게임입니다.
캐릭터는 자동으로 전진하며, 플레이어는 좌우 이동과 점프를 통해 장애물을 피하고 코인을 수집합니다.
벽면에 부딪히면 중력 방향이 90도 회전하여 새로운 관점에서 게임이 계속됩니다.

---

## 🎯 게임 목표

- **코인 수집**: 맵에 생성되는 코인을 최대한 많이 수집하세요
- **장애물 회피**: 다가오는 장애물과 충돌하지 마세요
- **생존**: 최대한 오래 살아남아 높은 점수를 달성하세요

---

## 🎮 조작법 (필수)

### 기본 조작
| 키 | 기능 | 설명 |
|---|---|---|
| **← 왼쪽 방향키** | 좌로 이동 | 캐릭터를 왼쪽으로 이동시킵니다 |
| **→ 오른쪽 방향키** | 우로 이동 | 캐릭터를 오른쪽으로 이동시킵니다 |
| **Space** | 점프 | 캐릭터가 점프합니다 (공중 제어 가능) |
| **C** | 프로젝타일 발사 | 전방으로 프로젝타일을 발사합니다 |

### 자동 기능
- **자동 전진**: 캐릭터가 자동으로 전방으로 이동합니다
- **중력 전환**: 벽면 충돌 시 자동으로 중력 방향이 90도 회전합니다

## 🎛️ 게임 제어 (UI)

### 게임 컨트롤 패널 (우측 하단)
화면 우측 하단에 게임 컨트롤 버튼이 표시됩니다:

| 버튼 | 기능 | 활성화 조건 |
|---|---|---|
| **Start Game** | 게임 시작 | NotStarted 상태 |
| **Pause Game** | 일시정지 | Playing 상태 |
| **Resume Game** | 재개 | Paused 상태 |
| **Restart Game** | 재시작 | Paused, GameOver, Victory 상태 |

### HUD (좌측 상단)
게임 플레이 중 화면 좌측 상단에 실시간 정보가 표시됩니다:

- **게임 상태**: Not Started / Playing / Paused / Game Over / Victory
- **스코어**: 현재 획득한 점수
- **타이머**: 경과 시간 (MM:SS 형식)

## 🌟 게임 메커니즘

### 1. 중력 전환 시스템
- **작동 원리**: 캐릭터가 벽면에 충돌하면 중력이 90도 회전
- **회전 애니메이션**: 부드러운 회전 효과 (약 0.5초)
- **회전 중 제한**: 회전 애니메이션 동안 이동 및 중력이 일시 정지
- **4방향 순환**: 아래 → 우측 → 위 → 좌측 → 아래 순으로 중력 방향 변경

### 2. 코인 수집
- **위치**: 맵 곳곳에 배치된 회전하는 금화
- **효과**:
  - 수집 시 점수 증가
  - 랜덤 색상의 라이트 효과
- **충돌 감지**: BoxComponent 기반 오버랩 이벤트

### 3. 장애물
- **종류**: 다양한 형태의 장애물이 자동 생성
- **충돌 결과**: 게임 오버
- **생성 패턴**: 거리 기반 자동 생성 시스템

### 4. 프로젝타일
- **발사**: C 키로 전방 발사
- **중력 적용**: 캐릭터의 현재 중력 방향을 따름
- **속도**: 1500 cm/s
- **생명 시간**: 5초

## 📊 게임 상태

### NotStarted (시작 전)
- 게임 시작 전 대기 상태
- **Start Game** 버튼으로 시작

### Playing (플레이 중)
- 게임이 진행 중인 상태
- 타이머가 작동하며 점수 획득 가능
- **Pause Game** 버튼으로 일시정지 가능

### Paused (일시정지)
- 게임이 일시정지된 상태
- 타이머 및 모든 게임 로직 정지
- **Resume Game**으로 재개 또는 **Restart Game**으로 재시작

### GameOver (게임 오버)
- 장애물과 충돌하여 게임 종료
- 화면 중앙에 **"GAME OVER"** 팝업 표시 (빨간색)
- 최종 스코어와 시간 표시
- **Restart Game** 버튼으로 재시작

### Victory (승리)
- 특정 목표를 달성하여 승리
- 화면 중앙에 **"VICTORY!"** 팝업 표시 (녹색)
- 최종 스코어와 시간 표시
- **Restart Game** 버튼으로 재시작

## 🎨 캐릭터 설정

### 이동 파라미터 (RunnerCharacter.lua)
```lua
MaxWalkSpeed = 15.0         -- 최대 이동 속도 (cm/s)
AutoForwardSpeed = 1.0      -- 자동 전진 입력 크기
StrafeSpeed = 1.0           -- 좌우 이동 입력 크기
JumpZVelocity = 35.0        -- 점프 초기 속도 (cm/s)
GravityScale = 0.1          -- 중력 스케일
AirControl = 0.3            -- 공중 제어력 (0.0 ~ 1.0)
```

### 프로젝타일 설정
```lua
ProjectileSpeed = 1500.0    -- 발사체 속도 (cm/s)
ProjectileGravityScale = 1.0 -- 발사체 중력 스케일
ProjectileLifespan = 5.0    -- 발사체 생명 시간 (초)
```

## 💡 플레이 팁

### 초보자 팁
1. **점프 타이밍**: 장애물 직전에 점프하면 안전하게 회피 가능
2. **좌우 이동**: 코인 수집 시 미리 위치 조정
3. **중력 전환 주의**: 벽면 충돌 전 미리 다음 방향을 예측
4. **회전 중 대기**: 중력 회전 애니메이션이 끝날 때까지 기다리기

### 고급 팁
1. **공중 제어**: 점프 중에도 좌우 이동 가능 (AirControl 0.3)
2. **프로젝타일 활용**: 중력 방향에 따라 포물선 궤적 변화
3. **연속 점프**: 착지 직후 바로 점프하여 빠른 이동
4. **벽면 활용**: 의도적으로 벽면에 부딪혀 중력 방향 변경

## 🔧 개발자 정보

### 사용 기술
- **엔진**: Custom C++ Game Engine (Unreal-like Architecture)
- **렌더러**: DirectX 11
- **스크립팅**: Lua 5.4 + Sol2
- **물리**: Custom Character Movement Component
- **UI**: ImGui

### 좌표계
- **DirectX11 Z-Up Left-Handed**: Z축이 위를 향하는 왼손 좌표계

### 주요 시스템
- **코루틴 시스템**: 부드러운 중력 회전 애니메이션
- **Delegate 시스템**: TWeakPtr 기반 안전한 이벤트 처리
- **BVH 충돌 시스템**: 효율적인 충돌 감지
- **Hot Reload**: Lua 스크립트 실시간 수정
